# v1.0.4

## 更新内容

这个版本新增了更适合普通用户的“沿用当前线路”切换方式，降低因为 provider 变化导致聊天记录分散的风险。

### 主要改进

- 新增 `沿用当前线路（推荐）` 线路类型。
- 切换配置时会根据当前 Codex 配置自动判断应该继续使用内建 `openai` 线路，还是沿用当前自定义 provider。
- 新增固定线路保存提醒：当用户选择 `官方线路地址` 或 `独立线路配置` 时，会提示聊天记录可能分散，并建议改用 `沿用当前线路`。
- 导入当前配置时默认使用 `沿用当前线路`，减少新手误改 provider 的概率。
- README 已更新安装包版本和“沿用当前线路”的使用说明。

### 适用场景

- 你只想切换账号或 API Key，不想手动理解 provider。
- 你希望尽量保留原来的 Codex 会话上下文和聊天记录归属。
- 你需要在官方线路、自定义线路、Codex 桌面端等读取同一套配置的环境之间保持更稳定的切换体验。

### 安装包
